# Learnova Data Report

## Dataset Components

| Dataset | Purpose |
|---|---|
| learner_profiles.csv | Learner characteristics and goals |
| learner_activity.csv | Learning interactions |
| assessments.csv | Assessment outcomes |
| resources.csv | Educational resource catalog |

## Data Preparation
1. Validate schema.
2. Remove duplicates.
3. Validate ranges.
4. Handle missing values.
5. Normalize/encode features.
6. Engineer learner-level and topic-level features.
7. Prevent temporal leakage.

## Important Variables
- score
- quiz_score
- completion_rate
- difficulty
- time_spent_min
- attempts
- hint_used

## Data Privacy
The included data is synthetic. Real student data should not be uploaded to a public GitHub repository without appropriate authorization, anonymization, and legal/ethical review.
